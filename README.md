## 📌 About the Project

This website was created to present my personal CV in a modern and interactive way.  
It includes information about my education, experience, skills, languages, certificates, and interests.

The goal of this project is to make it easier for employers to view my profile online in a professional format.

---

## 🚀 Features

- Responsive design for all devices
- Multi-section CV layout
- Language switching system
- Certificates viewer
- Interactive UI elements
- Review system
- Clean and modern design
